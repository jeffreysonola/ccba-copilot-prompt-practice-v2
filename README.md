# CCBA Copilot Prompt Practice v2

The second, independently published participant dashboard for the CCBA executive Microsoft 365 Copilot session on 9 October 2026.

## Features

- Start Here orientation and prompting foundations
- Work IQ in four levels
- Daily executive scan with save and schedule step
- Custom instructions, Memory, private reflection, and Prompt Coach
- Researcher, Word, Legal Agent, Excel, PowerPoint, and Outlook exercises
- Optional prompts and six role-based templates
- Individual copy controls for every prompt
- Downloadable Word, Legal Agent, and Excel exercise files
- Responsive desktop and mobile layouts
- CCBA branding and theme-aware presentation

## Run locally

Keep `index.html` and the `assets` folder together, then open `index.html` in a modern browser.

## Repository contents

- `index.html` - self-contained dashboard application
- `prompts.json` - source of the v2 participant prompt wording
- `CHANGES-v2.md` - v2 content and acceptance specification
- `assets/ccba-logo.png` - CCBA logo
- `assets/CCBA_Q3_2026_Commercial_Business_Review_PreRead.docx` - Word exercise
- `assets/CCBA_Q3_2026_Sales_Revenue_Tracker.xlsx` - Excel exercise
- `assets/CCBA_Packaging_Supplier_Agreement_DEMO.docx` - Legal Agent supplier agreement
- `assets/CCBA_Procurement_Legal_Playbook_DEMO.docx` - Legal Agent review playbook
